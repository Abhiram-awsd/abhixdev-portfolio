Put your photos in this folder, then list them in the `PHOTOS` array near the top of the script in `index.html`:

```js
const PHOTOS = [
  {src:"photos/sunset.jpg", alt:"Sunset over the lake", caption:"Golden hour", place:"Hyderabad"}
];
```

Keep each image under about 400 KB (1600 px on the long side is plenty) so the page stays fast.
